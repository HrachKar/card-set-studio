# Card Set Studio

Инструмент «под ключ» для коллекционных наборов карточек в стиле референсов из игры (Playrix).

**Вход:** тема набора и свободные пожелания. Больше ничего.
**Выход:** 3 варианта набора по 10 карточек (категории 1–4, без золотых), склейки в виде игрового окна 5×2 и zip-архив со всеми картинками по отдельности.

Работает как скилл Claude Code: геймдизайнер пишет обычными словами, например «сделай набор Вестерн, побольше еды», а агент сам составляет список объектов, проверяет его, генерирует картинки и показывает результат.

---

## Установка за 5 минут (Mac)

Нужно один раз.

**1. Python 3.10+.** Проверьте в Терминале:
```bash
python3 --version
```
Если команды нет, поставьте с https://www.python.org/downloads/ (или `brew install python`).

**2. Claude Code.** Инструкция: https://docs.claude.com/en/docs/claude-code/setup. Проверка: `claude --version`.

**3. Репозиторий и зависимости:**
```bash
git clone <ссылка на репозиторий> card-set-studio
cd card-set-studio
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**4. Ключ OpenAI.** Генерация картинок и судья работают через OpenAI API. Ключ: https://platform.openai.com/api-keys. Добавьте его в профиль, чтобы не вводить каждый раз:
```bash
echo 'export OPENAI_API_KEY="sk-..."' >> ~/.zshrc
source ~/.zshrc
```
Ключ Gemini (`GEMINI_API_KEY`) не нужен. Он использовался только для сравнения моделей (`studio/bench.py`).

Ключ никогда не вставляйте в чат с Claude и не коммитьте в репозиторий.

## Как пользоваться

```bash
cd card-set-studio
source .venv/bin/activate
claude
```
И напишите задачу, например:

> Сделай набор «Космоопера». Пожелания: как Звёздные войны, но без клонов.

Дальше агент работает сам (инструкция для него в `.claude/skills/card-set/SKILL.md`):

1. Составляет 25–30 кандидатов и отбирает из них 3 варианта по 10. Это текст, бесплатно.
2. Проверяет списки кодом без API: раскладка категорий, разнообразие классов, соседние фоны.
3. По желанию показывает список на утверждение («с проверкой»). По умолчанию идёт дальше сам.
4. Генерирует картинки: около 10–15 минут и около $8–9 за 3 варианта.
5. Показывает склейки и отдаёт архив.

**Правки** тоже обычными словами: «B4 перегенерируй, колёса крупнее», «в A7 вместо пирога поставь кофейник», «в C2 возьми второй вариант».

### Что получится

Всё в `runs/<имя прогона>/`:

| Файл | Что это |
|---|---|
| `<имя>_cards.zip` | **главное:** все карточки отдельными PNG (полный размер и 430×480), склейки, отчёт |
| `sheets/overview.png` | все варианты под референсным сетом из игры |
| `sheets/window_A.png` … | вариант в виде игрового окна 5×2 |
| `sheets/candidates_A.png` … | все кандидаты с оценками судьи, выбранный обведён |
| `report.md` | состав наборов, оценки, стоимость |

### Без Claude Code
```bash
python3 -m studio new --theme "Wild West" --wishes "уютный, побольше еды"
```
Список объектов тогда составляет GPT-5.5 по тем же правилам. Этот путь запасной и после правил 21.11 не перепроверялся. Основной путь — через Claude Code.

Готовые проверенные списки 4 жанров лежат в `studio/examples/`. Их можно сгенерировать сразу:
```bash
python3 -m studio new --theme "Вестерн" --sets studio/examples/sets_wild-west.json --name my-west
```
Проверка без затрат: добавьте `--stop-after dry`.

## Как устроено

```
тема + пожелания
   │
1. Составление (Claude Code + studio/rules.md)
   25–30 кандидатов → отборщик (отдельный агент) → 3 варианта по 10.
   Правила: сет = весь жанр; не меньше 6 классов объектов, не больше 2 на класс,
   не больше 2 носимых; без гибридов; одна главная карта-символ жанра.
   │
2. Раскладка без API (studio/layout.py, добавлено 22.11)
   код сам перемешивает порядок карт и выбирает цвет фона из 2–3 вариантов составителя:
   главная карта последняя, не больше 2 карт одной категории подряд, соседние фоны разные,
   не больше 3 тёплых или холодных подряд, у каждого варианта и сета своя раскладка.
   Проверка: python3 -m studio.layout studio/examples/sets_*.json
   │
   Проверка без API (studio/compose.py: validate)
   категории 3/2/3/2 ±1, все 4 категории, у карт кат.1–3 есть цвета фона,
   узор темы не больше чем на 3 картах, названия 1–2 слова, стоп-лист чужих товарных знаков.
   │
3. Промпты (studio/prompts.py)
   шаблон на каждую категорию + общий стиль-блок + запреты.
   │
4. Генерация (GPT Image 2.6 Sunburst, medium, 864×960)
   к каждому запросу прикладываются 3 эталонных арта той же категории (references/).
   3 кандидата на карточку.
   │
5. Судья (GPT-5.5 vision, studio/judge.py)
   чек-лист 5 пунктов × 0–2, сравнение с эталонами, порог 9 из 10.
   Жёсткие дефекты (текст, люди, обрезка, несколько объектов, рамка, мрак) валят сразу.
   Если никто не прошёл, второй раунд с подсказкой судьи. Больше 2 раундов на карту не бывает.
   Потолок бюджета MAX_RUN_USD = $12 на прогон: после него вторые раунды не запускаются,
   карта берёт лучшего кандидата из первого раунда (видно в report.md и в логе [budget]).
   │
6. Слепая проверка (studio/blindcheck.py)
   отдельная модель угадывает объект без подписи.
   │
7. Склейки, отчёт, zip (studio/sheet.py, studio/pipeline.py)
```

**Где живёт стиль.** Стиль не зависит от чата: он в файлах репозитория. Это стиль-блок в `studio/prompts.py`, эталоны в `references/` и критерии судьи в `studio/judge.py`. Своих LoRA нет: Playrix их не даёт, обучение своей отложили.

**Прозрачность.** Ничего не удаляется: в папке прогона лежат списки, все промпты (`prompt_rN.txt`), все кандидаты (`rN_i.png`), вердикты судьи (`judge_rN.json`) и расход (`usage.json`).

## Настройки
- `studio/config.py`: модели, число кандидатов, порог судьи, раунды, потолок бюджета на прогон (MAX_RUN_USD, по умолчанию $12, 0 = без потолка), параллельность, эталоны по категориям, цены.
- `studio/rules.md`: правила составления набора, обычным текстом.
- `studio/prompts.py`: стиль-блок и шаблоны промптов.

## Документы
- `docs/style-bible.md`: анализ референсов, принципы набора и стиля.
- `docs/rating-checklist.md`: чек-лист оценки карточки (тот же у человека и у судьи).
- `docs/restrictions-audit.md`: откуда взялся каждый запрет и что с ним сделали.
- `docs/research/`: исследование генераторов и причин «пластикового» стиля.
- `docs/history/`: черновики правил и списков по итерациям.

## Ограничения
- Золотые карты (кат. 5, персонажи в сценке) не делаются.
- Животные с мордами и эмоциями читаются как персонажи, а это близко к кат. 5. Для объектных сетов лучше брать предмет (яйцо дракона, седло).
- Судья тоже модель: иногда ошибается. Финальный выбор за геймдизайнером.
- Лимит OpenAI: 20 входных картинок в минуту на организацию, поэтому 4 запроса параллельно.
- Стоимость: около $0.06 за картинку; 3 варианта стоят около $8–9 вместе с судьёй.

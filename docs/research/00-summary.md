# Сводка ночного ресерча 21.11

Всё бесплатно: веб и чтение файлов, платные API не вызывались. Детали и ссылки лежат в файлах 01–04. Пометки в них: [V] проверено, [I] вывод.

## Риски
1. **Пластик сделали мы сами, библия тут ни при чём.** В ww-02 в стиль-блок попало «toy-like ... smooth surfaces + glossy highlights». Чек-лист и судья хвалят «гладкий игрушечный пластик», поэтому судья выбирает самого пластикового кандидата. Стиль-блок 20.11 тот же, что в ww-02. Сломалось из-за слов составителя: chrome, neon, glowing, crystal, golden-hour (02).
2. **Плохие картинки пересвечены и плоские по тону.** Детализация тут не причина: мелкая фактура хорошие и плохие почти не различает. Если просто упростить, вернётся проблема ww-01 (02).
3. **Сама Playrix держит стиль через LoRA** (это видно по их вакансии). Свои LoRA Playrix для тестового не даёт, поэтому стабильность нужно показать процессом (03).
4. **Список моделей устарел.** gpt-image-2 deprecated, есть 2.5 и 2.6. Midjourney без API, и его ToS запрещает автоматизацию. Krea styles, Scenario, Layer и Ideogram custom обучают модель, то есть это та же LoRA (04).
5. Fandom-вики заблокированы. Списков карт Gardenscapes и Homescapes нет, есть только по игре-референсу (01).

## Принципы, которые упустили (01)
- Сет = место, повод или занятие, класс вещей сюда не подходит. Пример, Ski Resort: Luggage, Ski Pass, Snow Cannon, Ski Lift, Chalet, Warming Hut, Viewing Deck, Ski Trail, Hot Tub, Rentals.
- Гибридов в реальных списках нет ни одного. Магия сводится максимум к одному прилагательному: Frozen Rose, Ice Castle, Magic Portal.
- Названия карт — существительные из 1–2 слов. Самая звёздная карта сета — главный символ темы.

## Стиль: короткие правила (02)
- Тёплый свет сверху-слева, 3–4 ступени тона, контура нет.
- Тени сливовые (#483343, #51305c), серых нет.
- Глянец только у стекла, жидкости, леденцов и лака. Дерево, ткань, керамика и еда матовые или сатиновые. Металл — тёплая латунь, хрома нет.
- Фон по насыщенности не слабее объекта. Правило библии «объект самый насыщенный» неверное.
- В 02 лежат готовый стиль-блок на 113 слов и негатив-лист.

## Рекомендации, по шагам
1. Заменить STYLE/NEG на блок из 02. Убрать «toy-like/glossy» из стиля, чек-листа и судьи. Бесплатно.
2. Составителю запретить chrome/neon/glowing/crystal/golden-hour и металлические поверхности в кат.3. Бесплатно, нужно согласовать с тредом про составителя.
3. Перейти на правку эталона вместо генерации по тексту: эталонная карточка из игры идёт первым входом, в промпте «change only the object» (03).
4. Дешёвый автофильтр по замерам: V mean > 0.86, V std < 0.14 или тёмного < 2% → в брак. Пороги ещё не проверены.
5. Если нужен новый генератор, бенч из 3 кандидатов: Recraft V4 Styles, Ideogram 3.0 со style refs, FLUX 3. Контроль: GPT Image 2.6 и NB Pro со слотами стиля. Около $25 на первый проход (04). Запускать только после «да» Грача.

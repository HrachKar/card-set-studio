# Как скилл работает с точками проверки

По умолчанию скилл делает всё сам, как раньше. Точки проверки необязательные: скилл предлагает их одной фразой, и если гейм-дизайнер молчит или отказывается, всё идёт автоматически.

## Режимы

| Режим | Как запустить | Что видит дизайнер | Цена до картинок |
|---|---|---|---|
| Авто (по умолчанию) | `new --theme ... --wishes ...` | Готовые листы через ~15 минут | — |
| С проверкой объектов | `new ... --stop-after compose` | Список объектов `review_sets.md` через 1–5 минут | ~$0.5 (только составитель) |
| Свой список объектов | `new --sets my.json` | Сразу картинки по его списку | $0 на составителя |
| Только промпты | `new --sets my.json --stop-after dry` | `review_prompts.md`, ни одного вызова API | $0 |

## Сценарий «с проверкой»

1. Дизайнер даёт тему и пожелания и говорит «с проверкой».
2. Скилл составляет наборы, картинок не делает. Показывает по каждому варианту строку из 10 объектов с категориями.
3. Дизайнер правит словами: «B4 замени на штурвал», «убери печенье», «в C больше еды». Скилл правит `compose/sets.json` и прогоняет проверку кода (сплит 3/2/3/2, соседние цвета, стоп-лист). Это бесплатно.
4. По желанию дизайнер смотрит промпты (`review_prompts.md`).
5. Дизайнер говорит «рисуй», и запускаются картинки (~$4–9 за 30 карточек). Дальше как раньше: листы, `regen`, `pick`.

## Зачем

- Самая дорогая ошибка этих дней — плохой список объектов. Его видели только на готовых картинках, за $4–9. Теперь список можно утвердить до картинок.
- Дизайнер может принести свой список. Формат — как в `night-2011/sets/*.json`. Скилл сам переведёт список из чата в этот формат.

## Что сделано в коде (20.11, без API)

- **Флаги:** `--stop-after compose|dry` и `--sets` в `python3 -m studio new`.
- **Файлы для проверки:** `review_sets.md` и `review_prompts.md` пишутся в каждый прогон, в том числе автоматический.
- **SKILL.md:** раздел «Optional checkpoints».
- **Тест:** проверено на ручном наборе супергероев в режиме dry, без ключей API.
- **Старые версии:** лежат в `runs/*_before_checkpoints_2011.*`.

## Открытые вопросы для Грача

- **Предупреждения валидатора.** Нужна ли точка проверки по умолчанию для новых жанров (космос, супергерои), где составитель чаще выдумывает? Сейчас валидатор только предупреждает.
- **Оружие.** Меч и молот — архетипы фэнтези и супергероев, но действующее правило запрещает любое оружие, даже игрушечное. Решение за тобой.
